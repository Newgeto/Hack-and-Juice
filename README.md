# Hack-and-Juice

Study project carried out at Epitech, focused on **application security / pentesting**.

The goal is to gather notes, examples and course material around the most common web vulnerabilities (OWASP-inspired), in order to understand:

- how they appear,
- what risks they involve,
- and how to prevent/fix them.

## Structure

The repository is organized by topic:

- `Broken Access Control`
- `Broken Anti Automation`
- `Broken Authentication`
- `Cryptographic Issues`
- `Improper Input Validation`
- `Injection`
- `Security through Obscurity`
- `Sensitive Data Exposure`
- `XSS`

Additional resources can be found in `img-au-cas-ou`.

## Usage

Each folder contains content related to its category (examples, explanations, screenshots, etc.).
